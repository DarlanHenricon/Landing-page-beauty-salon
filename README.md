# Vitryne Beauty

**Vitryne Beauty** is a landing page developed for a beauty and nail design professional, focused on service presentation, client acquisition, and appointment scheduling through WhatsApp.

This project was created as part of my web development studies and as a practical application of HTML, CSS, and JavaScript concepts in a real-world scenario. The goal was to build a modern, responsive, and mobile-friendly website that provides a simple and intuitive experience for potential clients who want to learn about the services and get in touch quickly.

## Features

* Fully responsive layout
* Direct WhatsApp integration
* Search Engine Optimization (SEO) structure
* Social media sharing meta tags
* Service catalog with pricing information
* Portfolio showcase
* Contact and location information
* Smooth navigation between sections
* Design focused on customer conversion

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Schema.org structured data for SEO

## Purpose

In addition to meeting a real business need, this project served as a practical learning experience for improving my front-end development skills, code organization, responsive design techniques, and user experience best practices. It represents one of my efforts to transform academic knowledge into functional solutions that can be applied in real business environments.
